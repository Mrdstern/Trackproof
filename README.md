# TrackProof

TrackProof is a mobile-first browser app for album evidence, release prep, and provenance documentation.

## GitHub Pages

The app is served from the repository root using `index.html`.

To publish with GitHub Pages:
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

The live site should then be available at:

`https://mrdstern.github.io/Trackproof/`

## Storage

This MVP stores app data locally in the browser using localStorage. No API or paid backend is required.
